# SEO audit — 2026-09-23

The cahier des charges asks for an "SEO-first" storefront. This is the page-by-page check of
what the frontend now emits, after adding `sitemap.xml`, `robots.txt`, canonical/hreflang on
every page and structured data on the pages that matter for search.

## Site-wide

| Item | Status | Where |
|---|---|---|
| Server-rendered HTML for every public page (no client-only content for crawlers) | ✅ | App Router server components; listing/product/category/store data fetched on the server |
| `metadataBase` + absolute canonical URLs | ✅ | `src/lib/seo.ts` (`NEXT_PUBLIC_SITE_URL`), root layout |
| hreflang `en` / `fr` / `x-default` on every page | ✅ | `seo()` helper, applied per page |
| Open Graph + Twitter card (title, description, image when available, locale) | ✅ | `seo()` helper |
| `sitemap.xml` — static routes × 2 locales + every category, published listing and active store, with hreflang alternates, revalidated hourly | ✅ | `src/app/sitemap.ts` (single file up to ~5,000 URLs per collection; move to `generateSitemaps()` beyond that) |
| `robots.txt` — allows everything public, blocks account/seller/admin/cart/checkout/wishlist/auth/search in both locales, points at the sitemap | ✅ | `src/app/robots.ts` |
| Organization + WebSite (with SearchAction) structured data | ✅ | home page |
| Clean URLs: English at `/`, French at `/fr/…`, no query strings needed for indexable pages | ✅ | next-intl `localePrefix: "as-needed"` |
| Pagination/filters keep the base page as canonical (`?page=2&sort=…` never becomes a duplicate) | ✅ | `seo()` ignores query strings |
| Language switch keeps the same path (crawlers see a 1:1 mapping) | ✅ | `LanguageSwitcher` |
| Images with `alt`, lazy-loaded except the hero (`priority`) | ✅ | `next/image` throughout |
| PWA manifest, theme colour, icons | ✅ | `src/app/manifest.ts` |
| Core Web Vitals | ⚠️ not measured | run Lighthouse against the production build (`next build` + `next start`) once deployed |

## Still to do for search performance

1. **Measure** — Lighthouse / PageSpeed on the deployed site (LCP is driven by the hero photo and
   fonts; five Google Fonts families are loaded, consider trimming to three).
2. **FAQPage schema** on `/help/faq` and `/how-it-works` (rich results).
3. **Product images on R2 with descriptive filenames + alt text from the seller** — today alt
   text is the listing title.
4. **Real content depth** — category pages have no editorial intro text; a short unique
   paragraph per top-level category helps ranking for "buy X in Cameroon" queries.
5. **Google Search Console + Bing Webmaster** — submit the sitemap after the domain exists.
